Zero-Persistence Guarantee & Ephemeral Memory State

Important Architecture Notice: CIX operates exclusively on stateless worker execution nodes. Transactional data, RFM matrices, and ML vectors are loaded directly into RAM and are never persisted to a hard drive or external SQL database. Restarting the session or terminating the worker pod purges the volatile buffer irreversibly.
